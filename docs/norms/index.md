# 规范页总览

> 适用定位：企业级授权、策略与高风险动作治理规范目录
>
> 范围说明：本目录聚焦授权模型、策略资产化与人工复核三类治理规范，确立平台长期可审计、可管控的运行基线。

## 规范清单

| 规范 | 类型定位 | 核心职责 |
| --- | --- | --- |
| [RBAC + ABAC](/norms/rbac-abac) | 授权模型规范 | 统一静态角色授权与动态属性上下文约束，收敛应用、知识与工具访问权限 |
| [Policy as Code](/norms/policy-as-code) | 策略治理规范 | 将权限、风控、路由与阈值规则沉淀为可版本化、可评审、可回滚的策略资产 |
| [Maker-Checker](/norms/maker-checker) | 人工审批与双人复核规范 | 确立高风险动作的发起与批准分离机制，强制人工确认与全链路留痕 |

## 职责边界

本目录各规范页聚焦企业级平台在授权模型、策略发布与人工审批等维度的治理原则、落地规则与审计要求，不替代具体组件的运维配置说明。
